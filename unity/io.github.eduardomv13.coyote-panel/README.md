# DG-LAB Coyote Panel for VRChat Avatars

A hand-held control panel for a DG-LAB Coyote 3.0 that you install on a VRChat avatar with one menu click
(**Tools > Coyote Panel > Install on selected avatar**). It needs **Modular Avatar** and the VRChat Avatars SDK, and it
talks to the [coyote-vrchat](https://github.com/eduardomv13/coyote-vrchat) PC program over VRChat OSC.

**The full guide, the safety notes and the list of what has and has not been tested are here:
[unity/README.md](https://github.com/eduardomv13/coyote-vrchat/blob/main/unity/README.md).**
Read the safety section before you upload an avatar that has this panel.

PC only. Not tested on Quest/Android.
